# Bài 4: Kiểm thử đa hệ điều hành với Matrix Strategy

- Workflow `.github/workflows/bai4-matrix.yml` chạy đồng thời trên `ubuntu-latest`, `windows-latest` và `macos-latest`.
- Sử dụng `java.nio.file.Path.of(...)` và `File.separator` thay cho dấu gạch chéo cứng (`/` hoặc `\`) để đảm bảo tương thích trên mọi hệ điều hành.
